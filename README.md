# 🛒 Zepto Clone – Online Grocery Shopping Application

A responsive online grocery shopping web application inspired by Zepto, developed using HTML, CSS, and JavaScript. The application provides an interactive shopping experience with product browsing, search, category filtering, cart management, and wishlist functionality.

## 🚀 Features

- **Responsive Homepage:** Clean interface with navigation, promotional banners, and product categories.
- **Product Listing:** Dynamically fetch and display products using the DummyJSON REST API.
- **Product Search:** Search and filter products based on user input.
- **Category Browsing:** Explore products through different categories.
- **Shopping Cart:** Add and remove products and manage product quantities.
- **Wishlist:** Save and manage favorite products.
- **Local Storage:** Maintain cart and wishlist data across browser sessions.
- **Location Detection:** Detect user location using the browser Geolocation API.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- DummyJSON REST API
- Browser Local Storage
- Geolocation API

## ⚙️ Installation and Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/NemalikondaUmesh/Zepto-Clone.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Zepto-Clone
   ```

3. Open the `index.html` file in your browser.

4. Alternatively, use the Live Server extension in Visual Studio Code to run the application.
